## 🎯 معايير أي مشروع جديد يضاف في هذا المجلد:
1. **حل مشكلة حقيقية**: محاكاة سيناريو بيزنس واقعي (خدمة عملاء، فحص كود، أبحاث سوق، تحليل عقود).
2. **فصل واضح للمسؤوليات**: توضيح الحالة (`State`)، العقد (`Nodes`)، والتفرعات الشرطية (`Edges`).
3. **دفتر تفاعلي جاهز للتشغيل (`.ipynb`)**: مدعوم بشرح تفصيلي باللغة العربية واختبارات حية.
4. **توثيق كامل (`README.md`)**: رسم بياني معماري (`Mermaid Diagram`) يوضح تدفق البيانات.
