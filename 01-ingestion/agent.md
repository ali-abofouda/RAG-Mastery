# دور الـ Agent في مرحلة إدخال ومعالجة البيانات (01-ingestion)

هذا الملف يحدد القواعد وهيكل العمل المنظم لمرحلة **01-ingestion** في مسار تعلّم RAG.

---

## 1. الهيكل التنظيمي للمرحلة (Section Architecture)

ينقسم مجلد `01-ingestion/` إلى:
1. **10 مجلدات فرعية للمناهج والمراجع:**
   * `01-environment-setup/` : تجهيز بيئة العمل باستخدام UV وحزم LangChain.
   * `02-document-structure/` : بنية كائن الـ Document والميتا-داتا في LangChain.
   * `03-text-loaders/` : استيراد ومعالجة الملفات النصية الخام.
   * `04-text-splitting/` : استراتيجيات وتقنيات تجزئة النصوص (Chunking).
   * `05-pdf-parsing/` : استخراج وتحليل مستندات PDF.
   * `06-pdf-advanced-issues/` : حل مشكلات الـ PDF الشائعة (جداول، مسح ضوئي، تنسيقات معقدة).
   * `07-word-documents/` : استيراد وقراءة مستندات Word (DOCX).
   * `08-csv-excel/` : معالجة البيانات الجدولية (CSV & Excel).
   * `09-json-processing/` : قراءة وتحليل البيانات المهيكلة (JSON).
   * `10-sql-databases/` : ربط واستخراج البيانات من قواعد بيانات SQL.

2. **معمل التجارب المركزي للمستخدم (`playground/`):**
   * يحوي دفاتر التجارب الحرة مقسمة حسب الدروس:
     - `01-text-parsing.ipynb`: تجارب قراءة وتجزئة النصوص.
     - `02-pdf-parsing.ipynb`: تجارب استخراج وتحليل الـ PDF.
     - `03-word-parsing.ipynb`: تجارب مستندات الـ Word (.docx).
     - `04-csv-excel-parsing.ipynb`: تجارب البيانات الجدولية (CSV & Excel).
   * يعتمد على **مستودع البيانات المركزي في جذر المشروع (`data/`)** الذي يخدم جميع المراحل ومعمل التجارب دون تكرار.

---

## 2. الهيكل القياسي للمجلدات المرجعية (Reference Standards)

لكل مجلد من المجلدات المرجعية العشرة:
* **ملف الشرح النظري والعملي (`README.md`):** توثيق نظري وهندسي ومخططات توضيحية.
* **دفتر الملاحظات المرجعي (`[topic].ipynb`):** كود المحاضرة النموذجي والمسبوق بخلايا Markdown شارحة.

---

## 3. قواعد التعامل مع مجلد الـ Playground والتجارب الحرة

* مجلد `playground/` ودفاتر التجارب ومجلد `data/` الداخلي هو مساحة عمل المستخدم بالكامل.
* **قاعدة عدم التعديل التلقائي:** لا يمسح الـ Agent أو يعدل أي خلية أو ملف تجريبي كتبه المستخدم إلا بطلب صريح منه للتنظيم.
* **مهمة التنظيم عند الطلب:** عند طلب المستخدم صراحة تنظيم دفاتر الـ playground:
  1. الحفاظ على أسماء الدفاتر المرقّمة بحسب الترتيب المنطقي للدروس.
  2. تنظيم وتصنيف ملفات البيانات داخل المجلدات الفرعية المناسبة (`txt/`, `pdf/`, `docx/`).
  3. الحفاظ التام على نصوص وملاحظات وأكواد المستخدم الأصلية دون حذف أو اختراع.
