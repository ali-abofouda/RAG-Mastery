## 📐 3. تشريح دالة تشابه جيب التمام (Cosine Similarity Breakdown)

يقيس تشابه جيب التمام الزاوية $\theta$ المحصورة بين المتجهين، متجاهلاً أطوالهما (Magnitudes):

$$\text{Cosine Similarity}(\mathbf{u}, \mathbf{v}) = \cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$$

### تفسير القيم الناتجة:
* **$+1.0$ (أو قريبة من 1):** المتجهان يشيران إلى نفس الاتجاه تماماً (تطابق دلالي تام مثل `cat` و `kitten`).
* **$0.0$:** المتجهان متعامدان ($\theta = 90^\circ$)، مما يعني انعدام العلاقة الدلالية تماماً.
* **$-1.0$ (أو سالبة):** المتجهان متعاكسان تماماً في الاتجاه (معاني متنافرة أو متضادة مثل `cat` و `car`).

### كود الحساب المتجهي عبر NumPy:
```python
import numpy as np

def cosine_similarity(vec1: np.ndarray, vec2: np.ndarray) -> float:
    # 1. حساب الضرب النقطي (Dot Product)
    dot_product = np.dot(vec1, vec2)
    
    # 2. حساب المعيار الإقليدي (Magnitude / L2-Norm)
    norm_a = np.linalg.norm(vec1)
    norm_b = np.linalg.norm(vec2)
    
    # 3. القسمة لحساب جيب تمام الزاوية
    return float(dot_product / (norm_a * norm_b))
```

### نتائج حساب المحاضرة:
* $\text{sim}(\text{cat}, \text{kitten}) = \mathbf{0.996}$ $\to$ تطابق شبه تام!
* $\text{sim}(\text{cat}, \text{car}) = \mathbf{-0.4367}$ $\to$ تنافر دلالي واضح.

## ⚖️ 4. مقارنة مقاييس المسافات في قواعد بيانات المتجهات (Vector Distance Metrics)

في قواعد بيانات المتجهات (Vector DBs مثل Chroma, FAISS, Pinecone)، ستصادف ثلاثة مقاييس شائعة:

| المقياس | المعادلة الرياضية | المزايا | متى تختاره في الـ RAG؟ |
| :--- | :--- | :--- | :--- |
| **Cosine Similarity** | $\frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$ | محايد تماماً لطول النص، يقيس المعنى النقي. | **الخيار الافتراضي والأمثل** لمعظم تطبيقات RAG والنصوص متفاوتة الطول. |
| **Dot Product (Inner Product)** | $\mathbf{u} \cdot \mathbf{v}$ | فائق السرعة حاسوبياً (مجرد ضرب وجمع بدون جذور). | عندما تكون المتجهات معيرة مسبقاً بطول الوحدة ($\|\mathbf{u}\| = 1$). |
| **Euclidean Distance (L2)** | $\sqrt{\sum (u_i - v_i)^2}$ | يقيس المسافة الهندسية المباشرة بين النقطتين. | مفيد في بيانات الرؤية الحاسوبية أو عندما يكون طول المتجه ذا دلالة. |

## 🔬 5. كيف نتصور المتجهات الحقيقية؟ (Dimensionality Reduction & PCA)

بما أن العقل البشري وشاشات الحاسوب لا تستطيع إظهار فضاءات تحتوي على 384 أو 1536 بُعداً، تستخدم أنظمة الـ AI خوارزميات **تقليل الأبعاد (Dimensionality Reduction)**:
* **PCA (Principal Component Analysis):** تحليل المكونات الرئيسية، يقوم بتدوير الفضاء وإسقاط الأبعاد الكثيرة على البعدين الأكثر احتفاظاً بتباين البيانات (**Variance**).
* **t-SNE / UMAP:** خوارزميات غير خطية ممتازة لتصور العناقيد المعقدة في مجموعات البيانات الضخمة.

في الدفتر العملي قمنا بتطبيق الـ PCA على متجهات نموذج `all-MiniLM-L6-v2` الحقيقية وإسقاطها على 2D لإثبات أن المفاهيم النظرية تتطابق 100% مع الواقع العملي.
