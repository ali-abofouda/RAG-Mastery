* **المحاكاة الهندسية:** دور مهندس الذكاء الاصطناعي الميداني (Palantir/OpenAI Standard) بالتعاون مع الـ CTO.

  4. النشر السحابي الأولي على **Google Cloud Platform (GCP)**.

# 🛡️ المرحلة الثانية: شهر هندسة الإنتاج والتأهيل لسوق العمل (The Extra Mastery Month)

### الأسبوع 1: الـ Containerization و DevOps السحابي (Docker & Cloud Deploy)
* **الهدف:** ألا يعيش أي مشروع في كود محلي فقط، بل كأنظمة جاهزة للتشغيل بضغطة زر.
* **المهام العملية:**
  - كتابة `Dockerfile` متعدد المراحل (Multi-stage) لمشروع الـ HR ومشروع الـ FDE.
  - كتابة `docker-compose.yml` يشغل التطبيق مع قواعد بيانات Qdrant و MongoDB.
  - رفع الصور إلى Google Artifact Registry وتشغيلها عبر **Google Cloud Run**.

### الأسبوع 2: بروتوكول الـ Model Context Protocol (MCP) المتقدم
* **الهدف:** إتقان معيار Anthropic العالمي الحديث لاستدعاء الأدوات والأنظمة الخارجية.
* **المهام العملية:**
  - بناء سيرفر MCP محلي مخصص (Custom MCP Server) للتعامل مع بيانات وسياسات الموظفين.
  - ربط وكلاء LangGraph بسيرفرات MCP خارجية، وإبراز ذلك كمهارة فريدة ونادرة في الـ CV.

### الأسبوع 3: القياس الرقمي الصارم والأمان (Enterprise Ragas Evals & Guardrails)
* **الهدف:** تقديم أرقام ومقاييس حقيقية تثبت جودة النظام وتمنع الهلوسة في المقابلات.
* **المهام العملية:**
  - توليد Synthetic Test Datasets باستخدام Ragas.
  - استخراج تقرير تقييم رقمي يوضح: `Faithfulness`, `Answer Relevance`, و `Context Precision`.
  - تطبيق اختبارات الاختراق (Red-Teaming) وحماية المدخلات بفلاتر Model Armor.

### الأسبوع 4: احتراف الـ AI System Design وإطلاق البورتفوليو والـ CV النهائي
* **الهدف:** اقتناص الوظائف والتميز في المقابلات التقنية الكبرى.
* **المهام العملية:**
  - **موقع البورتفوليو (Next.js 15):** إطلاق المشاريع الثلاثة الكبرى (Hakeem AI, HR Policy RAG, AI FDE Platform) مع الـ Architecture Diagrams والـ Live Demos.
  - **السيرة الذاتية النهائية (`resume/cv.tex`):** صياغة الإنجازات والنتائج الرقمية المحققة بقالب Jake's Resume المعتمد.
  - **محاكاة مقابلات الـ AI System Design:** التدرب على سيناريوهات تصميم أنظمة RAG تتحمل ملايين الاستعلامات وتراعي الميزانية والـ Latency.
